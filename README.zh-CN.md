# PromptDock

**VS Code 的 AI 提示词管理工具**

PromptDock 是一款 VS Code 扩展，为你所有的 AI 提示词提供一个专属的管理空间——包括你自己编写的模板、面向常见工程任务的内置预设，以及你通过 Claude Code、GitHub Copilot Chat 和 Codex 发送过的完整历史提示词。不再重复手写同样的提示词，不再在聊天记录里反复翻找。所有提示词都有序整理、随时可搜，一键即可使用。

## 为什么选择 PromptDock？

AI 编程工具的效果，很大程度上取决于你给出的提示词质量。大多数开发者不得不凭记忆反复输入同样的提示词，在聊天记录里翻找历史，或把提示词零散地存在各种文本文件里。PromptDock 把你的整个提示词库放进侧边栏——结构化管理、保存为个人模板、并从你已经在用的每个 AI 工具中自动收录。

## 功能

### 我的模板（My Templates）

编写并整理你自己的提示词模板，按符合你工作方式的文件夹结构组织。首次运行时，PromptDock 会自动创建一套默认文件夹——需求（Requirements）、设计（Design）、开发（Development）、测试（Testing）、部署（Deployment）、维护（Maintenance）和智能体（Agents）——你可以随时自由增删改名。删除文件夹不会删除其中的模板，这些模板只会变为未归类状态。

### 内置预设

扩展内置了 12 条开箱即用的提示词，涵盖调试、重构、测试、文档、代码评审和性能优化场景，并已按场景预先归入对应文件夹。可一键将单个预设或全部预设导入"我的模板"。

### 来自 AI 工具的历史提示词

PromptDock 自动扫描你本地的 Claude Code、Copilot Chat 和 Codex 会话文件，将你发送过的所有提示词按工具、项目和会话分组呈现。启动时自动执行，且只重新扫描自上次同步以来变化的文件，历史记录再多也能保持流畅。你也可以随时手动触发同步。

### 全局搜索

侧边栏每个分区都有独立的即时搜索框。如果想一次性搜索所有模板、预设和导入历史，可在命令面板中运行 **PromptDock: Search Prompts...**，选中结果后会在独立面板中展示完整内容，并提供一键复制、插入，以及保存到"我的模板"的操作。

### 即时使用提示词

点击提示词名称即可一步完成复制到剪贴板并插入光标处（行为可配置）。提示词内容中的 `{selection}` 占位符会在复制或插入前自动替换为当前编辑器中选中的文本。

### 独立悬浮面板

点击任意分区（我的模板，或某个 AI 工具来源）上的 **+ New Window** 按钮，将其单独打开为分离面板，方便在编写代码时随时查阅提示词库。

## 配置项

| 设置项 | 说明 | 默认值 |
|---|---|---|
| `promptdock.defaultAction` | 点击提示词时的行为：`copyAndInsert`（复制并插入）、`copyOnly`（仅复制）或 `insertOnly`（仅插入）。 | `copyAndInsert` |

## 命令

所有命令均可在命令面板中通过 **PromptDock** 分类找到：

- **Search Prompts...** —— 一次性搜索所有提示词
- **Sync Prompts from Claude Code / Copilot Chat / Codex** —— 手动刷新导入的历史记录
- **New Prompt Template...** / **New Folder...** —— 在侧边栏中添加到"我的模板"
- **Import to My Templates** / **Import All Presets** —— 将内置预设复制到你自己的模板库

## 隐私说明

PromptDock 管理的所有内容——模板、文件夹以及导入的历史记录——都只保存在 VS Code 自身的扩展存储中，不会发送到任何外部服务。导入历史记录时，也只会读取你本机已有的会话文件。
