# PromptDock

无需离开 VS Code，即可管理、复用你常用的 AI 提示词。PromptDock 拥有独立的活动栏视图，把三类内容集中到一处：你自己编写的提示词模板、内置的常用预设库，以及自动从 Claude Code、GitHub Copilot Chat 和 Codex 拉取的历史提示词。

## 功能

### 我的模板（My Templates）

编写并复用你自己的提示词模板，并按文件夹分类管理。首次运行时，PromptDock 会自动创建一组默认文件夹——需求（Requirements）、设计（Design）、开发（Development）、测试（Testing）、部署（Deployment）、维护（Maintenance）和智能体（Agents）——你也可以随时新增、重命名或删除自己的文件夹。删除文件夹不会删除其中的模板，这些模板只会变为未归类状态。

### 内置预设

扩展内置了 12 条开箱即用的提示词，涵盖调试、重构、测试、文档、代码评审和性能优化等场景，它们会自动出现在最匹配的文件夹中（例如测试类提示词出现在**测试**文件夹下，调试和重构类提示词出现在**开发**文件夹下）。你可以一键导入单个预设，也可以一键导入全部预设到"我的模板"——导入后会自动归入对应的文件夹。

### 导入的历史记录

PromptDock 会扫描你本地的 Claude Code、Copilot Chat 和 Codex 会话文件,并将你通过这些工具发送过的所有提示词呈现出来,按工具、项目、会话逐级分组。该扫描会在启动时自动执行,并且只重新扫描自上次同步以来发生变化的文件,因此即使历史记录很大也能保持流畅。你也可以随时手动触发同步。

### 全局搜索

侧边栏的每个分区都自带即时搜索框,输入时会按名称和内容实时过滤。如果想一次性搜索所有内容——模板、预设和导入的历史记录——可以在命令面板中运行 **PromptDock: Search Prompts...**;选中一条结果后,会在独立面板中展示完整内容,并提供一键复制、插入,以及(针对预设/导入的提示词)保存到"我的模板"的操作。

### 使用提示词

点击提示词名称即可一步完成复制到剪贴板并插入光标处(具体行为可配置,见下文),或使用专门的复制按钮仅复制到剪贴板。提示词内容中的 `{selection}` 占位符,会在复制或插入前自动替换为当前编辑器中选中的文本。

### 独立窗口

点击任意分区(我的模板,或某个来源如 Claude Code)上的 **+ New Window** 按钮,即可将该分区单独打开为一个分离的面板——便于在编写代码的同时随时查看你的提示词库。

## 配置项

| 设置项 | 说明 | 默认值 |
|---|---|---|
| `promptdock.defaultAction` | 点击提示词时的行为:`copyAndInsert`(复制并插入)、`copyOnly`(仅复制)或 `insertOnly`(仅插入)。 | `copyAndInsert` |

## 命令

所有命令均可在命令面板中通过 **PromptDock** 分类找到,包括:

- **Search Prompts...** —— 一次性搜索所有提示词,并在独立面板中查看结果
- **Sync Prompts from Claude Code / Copilot Chat / Codex** —— 手动刷新导入的历史记录
- **New Prompt Template...** / **New Folder...** —— 在侧边栏中添加到"我的模板"
- **Import to My Templates** / **Import All Presets** —— 将内置预设复制到你自己的模板库

## 隐私说明

PromptDock 管理的所有内容——你的模板、文件夹以及导入的历史记录——都只保存在 VS Code 自身的扩展存储中,不会发送到任何外部服务;导入历史记录时,也只会读取你本机已有的会话文件。
